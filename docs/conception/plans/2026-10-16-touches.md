# Touches personnalisées — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** chaque raccourci de LAFLEURMUSIC sur une touche ou une combinaison choisie, clapet ouvert et clapet fermé.

**Architecture :** un module de données pur `common/keymap.lua` partagé par l'interface et le gardien du clapet ;
`ui/src/input.lua` généralisé aux combinaisons quelconques ; un écran Touches + une capture ; le gardien lit la
manette en evdev et devient seul responsable des touches clapet fermé.

**Tech Stack :** Lua 5.1 / LuaJIT, LÖVE 11.5 sur la console, tests `luajit tests/run.lua`, simulateur de rendu (scratchpad).

**Spec :** `docs/conception/specs/2026-10-16-touches-design.md`

## Global Constraints

- Combinaison = une touche ou deux ; fenêtre 0,15 s ; clapet fermé : deux touches obligatoires.
- Touches utilisables clapet ouvert : x, y, start, select, l1, r1, l2, r2. Clapet fermé : les mêmes + a, b, up, down, left, right.
- Fixes clapet ouvert : croix, a = ok, b = back, menu = quit ; `ab_swap=on` échange ok et back.
- Défauts ouvert : playpause=start, next=r1, previous=l1, shuffle=y, repeat=x, now_playing=select, toggle_background=l1+r1.
- Défauts fermé : playpause=l2+r2, next=r1+r2, previous=l1+l2, shuffle="", repeat="".
- Format `settings.txt` : `key_open_<action>=l1+r1`, `key_closed_<action>=`, `ab_swap=off` (combinaison triée, `+`).
- Capture annulée après 5 s sans appui. L2/R2 en SDL : axe > 0,5 = appui, < 0,3 = relâchement.
- Textes FR + EN ; commits en anglais, sans attribution ; aucun visuel nouveau sans maquette validée (déjà validée : `maquettes/simulation/touches.png`).
- Écriture sur la console : uniquement via `tools/install.sh` (jamais sed -i / rsync sur les partages).

## Review Focus

1. Réglage enregistré avec une touche que la console n'a plus le droit d'utiliser (ex. `key_open_shuffle=a`) → retomber sur le défaut, pas planter ni bloquer Valider.
2. Deux actions qui finissent sur la même combinaison après un `settings.txt` modifié à la main → la première dans l'ordre des actions garde la combinaison, l'autre passe à "".
3. Clapet fermé avec l'appli ouverte : une touche ne doit rien faire dans l'interface (ni naviguer, ni quitter).
4. L1 maintenu longtemps puis R1 (hors fenêtre) → « précédent » seul, jamais Arrière-plan.
5. Gardien sans manette trouvée → le clapet marche comme avant.

### Task 1 : `common/keymap.lua`

**Files :** Create `common/keymap.lua`, Test `tests/test_keymap.lua`

**Interfaces — Produces :**
- `K.ACTIONS = { "playpause", "next", "previous", "shuffle", "repeat", "now_playing", "toggle_background" }` (ordre d'affichage) ; `K.CLOSED_ACTIONS = { "playpause", "next", "previous", "shuffle", "repeat" }`
- `K.DEFAULTS.open`, `K.DEFAULTS.closed` : table action → combo (string)
- `K.normalize(a, b) -> string` (`"r1","l1"` → `"l1+r1"` ; `b` nil → `a`)
- `K.split(combo) -> { btn [, btn] }`
- `K.valid(side, combo) -> bool` (side = `"open"` | `"closed"`)
- `K.load(settings) -> { open = map, closed = map, ab_swap = bool }`
- `K.store(settings, km)` (écrit les clés dans la table settings ; la sauvegarde reste `S.save`)
- `K.assign(km, side, action, combo) -> ok, err` (`err = "reserved"` ; conflit → échange)
- `K.reset(km, side)` ; `K.label(combo) -> string`

- [ ] **Step 1 : tests** — dans `tests/test_keymap.lua` :
  - « défauts sans réglages » : `K.load({}).open.toggle_background == "l1+r1"`, `.closed.next == "r1+r2"`, `.closed.shuffle == ""`, `ab_swap == false` ;
  - « relit ce qui a été stocké » : `assign(km,"open","shuffle","l2")`, `store(t,km)`, `t.key_open_shuffle == "l2"`, `K.load(t).open.shuffle == "l2"` ;

  - « libellés » : `label("l1+r1") == "L1 + R1"`, `label("select") == "SELECT"`, `label("") == "—"`, `label("up+a") == "↑ + A"` ;
  - « reset » : après assign, `K.reset(km,"open")` → défauts.
